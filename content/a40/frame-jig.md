Built a jig to hold the frame square and flat while it's welded: an I-beam base with two parallel rails running the length of the frame, tied together by three cross members. If the jig is off, the frame is off, and so is everything that bolts to it.

![Frame jig detail](/assets/projects/a40-austin/blog/frame-jig-2.jpg)

Tacked the cross members first, levelled and checked everything with several bubble levels, then welded it out.

## Checks before the frame goes on

Bubble levels only read level where they sit; twist and bow between those spots need a reference line. Before any frame work, and again whenever the jig has been moved:

1. **Flat:** run a taut string line, laser or long straightedge along each rail and across both diagonals. Shim out any twist.
2. **Square:** measure both corner-to-corner diagonals; they must match within 1–2 mm.
3. The jig's own welds pull it, so these checks count only if they were done after it was welded. Correct anything found before the frame rails go on.

The frame weld-out sequence is in [design finalization](./design-finalization#build-sequence).
